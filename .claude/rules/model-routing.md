# Aurex Model Routing Rule

Apply `FOUNDATION/MODEL-ROUTING-STANDARD.md` when model choice materially affects cost, quality, or risk.

- Do not use a premium model merely because it is available.
- QUICK work should prefer FAST when practical.
- STANDARD work should normally use STANDARD/Sonnet-class reasoning.
- DEEP work should mix model classes rather than using PREMIUM for every stage.
- Reserve PREMIUM/Opus-class reasoning for high-leverage synthesis, difficult escalation, or high-risk decisions.
- Route by both reasoning difficulty and consequence of error.
- For ambiguous technical work, gather evidence before escalating.
- After two focused, meaningfully different failed approaches, reassess the route instead of repeating the same attempt.
- When escalating, pass a compressed problem brief, not the entire conversation or repository.
- Do not re-run completed lower-cost research just because a premium model is now involved.
- If cheaper routing creates repeated rework, optimize total effort and escalate.
- Never lower verification, accessibility, security, SEO, conversion, or launch standards to save model usage.
