# Aurex Visual Reference Library

Use this directory as a curated input to art direction, not a mood-board dump or a source of layouts to clone.

## Structure

Store project-independent visual references under:

```text
references/
  visual/
    INDEX.md
    typography/
    composition/
    imagery/
    motion/
    interaction/
    mobile/
```

Create only the category folders a real reference needs. Keep client-confidential assets in the client repository, not here.

For every saved reference, add an entry to `visual/INDEX.md` containing:

- title and source URL or local asset path
- category and relevant page/viewport
- principle worth borrowing
- business or narrative use case
- what not to copy
- date reviewed

During art direction, select a small reference set for the current concept, normally three to five entries. Explain the principle each reference contributes. Do not ask the implementation to imitate an entire site.

The non-visual operating examples already in this directory remain valid and do not need to move.
